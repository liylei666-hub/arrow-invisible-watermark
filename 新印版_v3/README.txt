      11 组 Hamming(7,4)，码元按四个内孔配额交织（每组覆盖 3–4 个孔）。

配色：纯白底 (255)，深灰字 (58)
图上没有任何定位标记；信息藏在字母内孔边界的 ±6 px（±0.06 mm）径向微起伏里。

打印
----
1. PDF 按 100% 原尺寸打印，不要勾选"适合页面/缩放"。
2. 建议 600 dpi 以上；PNG 请勿再次缩放或重采样。
3. 若制版要求出血，四周等量加白边，不要裁切图内区域。

解码与判定
----------
小程序：直接拍摄。
命令行：python batch_decode.py 照片.jpg
服务端：POST /decode，carrier=inner；服务端自动先试 v3，CRC 不过再回退 v2。

通过条件：accepted=true 且 digits 与印版号码一致；
无码对照必须 accepted=false、digits=null。

注意
----
- 新印版需要服务端已部署支持 v3 的版本；旧服务会拒 v3 印版。
- 旧 v2 印版仍可解，两个版式共用同一次配准。
- 本目录是测试样张，不属于仓库正式资产，可随时删除。
